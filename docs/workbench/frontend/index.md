# Frontend workbench

Canonical source collections are separate from [learner practice](../../practice/frontend/). Textbook notes include the same files directly; old lesson URLs stay available.

- [Browser public search](./browser/): HTML-first server route, CSS, owned enhancement and authored multi-engine cases.
- [JavaScript lifetimes](./javascript/): bindings, checkpoints/disposal and optional IndexedDB source.
- [TypeScript contracts](./typescript/): generic relationship and links to the retained P-330 starter.
- [React](./react/): composition, dialogs, forms, component testing, tokens and a local interactive demo.
- [Next.js](./next/): runnable public read-only application, separate security integration fragments.
- [UI architecture](./architecture/): bounded data table and six synthetic behavior checks.

Install/run each dependency set in an isolated copy; keep mentoring templates and protected src/tests intact. [Verification](../../frontend/verification.md) names actual executed subsets and limitations. These examples perform no paid-service activation or published deployment.
