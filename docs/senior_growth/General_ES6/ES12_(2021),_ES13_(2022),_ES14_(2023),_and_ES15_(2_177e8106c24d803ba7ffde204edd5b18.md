# ECMAScript features from ES2021 to ES2024 {#es12-2021-es13-2022-es14-2023-and-es15-2024}

## **ES12 (ECMAScript 2021): Key Features**

### **Logical Assignment Operators** {#_1-logical-assignment-operators}

- Combines logical operations with assignment, simplifying code.

```jsx
let a = null;
let b = 5;

a ||= b; // Equivalent to: if (!a) a = b;
console.log(a); // 5

let c = true;
c &&= false; // Equivalent to: if (c) c = false;
console.log(c); // false

let d = null;
d ??= b; // Equivalent to: if (d === null || d === undefined) d = b;
console.log(d); // 5
```

---

### **Numeric Separators** {#_2-numeric-separators}

- Enhances readability of large numeric literals by allowing underscores as separators.

```jsx
const budget = 1_000_000; // One million
console.log(budget); // 1000000
```

---

### **`Promise.any`** {#_3-promise-any}

- Returns the first fulfilled promise, ignoring rejections.

```jsx
const promises = [
  Promise.reject("Error 1"),
  Promise.resolve("Success"),
  Promise.reject("Error 2"),
];

Promise.any(promises)
  .then((value) => console.log(value)) // "Success"
  .catch((error) => console.log(error));
```

---

### **`String.prototype.replaceAll`** {#_4-string-prototype-replaceall}

- Replaces all occurrences of a substring within a string.

```jsx
const text = "apple, banana, apple";
const newText = text.replaceAll("apple", "orange");
console.log(newText); // "orange, banana, orange"
```

---

## **ES13 (ECMAScript 2022): Key Features**

### **Top-Level `await`** {#_1-top-level-await}

- Allows the use of `await` at the top level of modules without wrapping in an async function.

```jsx
// In a module context
const data = await fetchData();
console.log(data);
```

---

### **Class Fields and Static Initialization Blocks** {#_2-class-fields-and-static-initialization-blocks}

- Introduces public and private class fields, along with static initialization blocks for complex static setup.

```jsx
class MyClass {
  static count = 0; // Public static field
  #name; // Private instance field

  constructor(name) {
    this.#name = name;
    MyClass.count++;
  }

  static {
    // Static initialization block
    console.log("Class initialized");
  }
}
```

---

### **`Array.prototype.at`** {#_3-array-prototype-at}

- Accesses elements at a given index, supporting negative indices for counting from the end.

```jsx
const array = [10, 20, 30];
console.log(array.at(1)); // 20
console.log(array.at(-1)); // 30
```

---

## **ES14 (ECMAScript 2023): Key Features**

### **Copying array methods** {#_1-copying-array-methods}

Arrays have `toReversed`, `toSorted`, `toSpliced` and `with`. TypedArrays have `toReversed`, `toSorted` and `with`, but no `toSpliced` (their length is fixed). These copy the outer collection, not nested object graphs.

- Introduces non-mutating methods for array manipulation.

```jsx
const arr = [3, 1, 4];

const reversed = arr.toReversed();
console.log(reversed); // [4, 1, 3]
console.log(arr); // [3, 1, 4] (original array unchanged)

const sorted = arr.toSorted();
console.log(sorted); // [1, 3, 4]
console.log(arr); // [3, 1, 4] (original array unchanged)

const spliced = arr.toSpliced(1, 1, 2);
console.log(spliced); // [3, 2, 4]
console.log(arr); // [3, 1, 4] (original array unchanged)

const newArr = arr.with(1, 2);
console.log(newArr); // [3, 2, 4]
console.log(arr); // [3, 1, 4] (original array unchanged)
```

---

### **`Array.prototype.findLast` and `findLastIndex`** {#_2-array-prototype-findlast-and-findlastindex}

- Retrieves the last element or index that matches a condition.

```jsx
const numbers = [1, 2, 3, 4, 5];

const lastEven = numbers.findLast((n) => n % 2 === 0);
console.log(lastEven); // 4

const lastEvenIndex = numbers.findLastIndex((n) => n % 2 === 0);
console.log(lastEvenIndex); // 3
```

---

### **Hashbang (`#!`) Grammar** {#_3-hashbang-grammar}

- Allows the use of hashbangs in JavaScript files, facilitating scripting in Unix-like environments.

```jsx
#!/usr/bin/env node
console.log("Hello, world!");
```

---

### **Symbols as WeakMap Keys** {#_4-symbols-as-weakmap-keys}

- Enables nonregistered symbols as WeakMap keys/WeakSet values; Symbol.for registered symbols are excluded.

```jsx
const wm = new WeakMap();
const sym = Symbol("key");
wm.set(sym, "value");
console.log(wm.get(sym)); // "value"
```

---

## **ES15 (ECMAScript2024): selected shipped language features**

```js
const { promise, resolve } = Promise.withResolvers();
resolve('ready');
console.log(await promise); // ready; top-level module context
const grouped = Object.groupBy([1, 2, 3], value => value % 2 ? 'odd' : 'even');
console.log(grouped.odd); // [1,3]; returned dictionary has a null prototype
```

Grouping and Promise.withResolvers are2024 examples. The latter exposes settlement functions but does not automatically cancel work. Use an existing promise API instead of wrapping it unnecessarily.

### Later features and proposals: keep dates distinct

- New Set methods are assigned to ECMAScript2025 in the TC39 finished list, even though implementations began shipping earlier.
- Temporal is not a2024 feature. The current TC39 finished list records its acceptance for ECMAScript2027. Acceptance into a future edition does not imply availability in the Node/browser version you deploy.
- The pipeline operator remains a Stage2 proposal as checked2026-10-20. The previous F#-style snippet was not standard JavaScript. Use standard chaining/composition unless the project deliberately pins a proposal transform.

```js
const result = [1, 2, 3].map(n => n * 2).filter(n => n > 2);
console.log(result); // [4,6], no proposal parser required
const setA = new Set([1, 2, 3]);
const setB = new Set([3, 4, 5]);
if (typeof setA.union === 'function') {
  console.log([...setA.union(setB)]); // [1,2,3,4,5]
  console.log([...setA.intersection(setB)]); // [3]
}
if (typeof globalThis.Temporal !== 'undefined') {
  console.log(globalThis.Temporal.Now.plainDateISO().toString());
}
```

For real date work, select the domain type: a birthday is a plain date, an audit event an instant, and a meeting often requires an IANA time zone plus a wall time. A support check is not a fallback implementation. Pin an appropriate maintained polyfill/library if needed and test DST ambiguity explicitly; do not silently substitute local Date arithmetic.

## Compatibility decisions and exercise

Language edition, proposal stage, engine shipping version, TypeScript declarations and bundler transform support are different facts. A new lib declaration can make code typecheck without installing its runtime API. Syntax not understood by the parser fails before a feature-detection branch can run; inspect transpiled output and dependency syntax too. Prefer the smallest demonstrated feature set for the support policy.


Official references: [TC39 finished proposals and assigned editions](https://github.com/tc39/proposals/blob/main/finished-proposals.md), [pipeline proposal](https://github.com/tc39/proposal-pipeline-operator), [Temporal documentation](https://tc39.es/proposal-temporal/docs/), [ECMAScript collections](https://tc39.es/ecma262/multipage/indexed-collections.html). Checked2026-10-20; local executable feature checks use Node24.18.0.


## Runtime probes and property order are separate compatibility checks

```js
function modernFeatureFixture() {
  const original = [10, 2, 30];
  const sorted = original.toSorted((a, b) => a - b); // Default Array sorting is string-based.
  const nested = [{ count: 1 }];
  const copied = nested.toReversed();
  const weak = new WeakMap();
  const local = Symbol('local');
  weak.set(local, 'held');
  let registeredRejected = false;
  try { weak.set(Symbol.for('registered'), 'invalid'); } catch (error) { registeredRejected = error instanceof TypeError; }
  const symbol = Symbol('metadata');
  const ordered = { b: 1, 10: 'ten', 2: 'two', a: 2, [symbol]: 3 };
  return { last: original.at(-1), sorted, original, shallow: copied[0] === nested[0],
    weakValue: weak.get(local), registeredRejected,
    typedSplice: typeof Uint8Array.prototype.toSpliced,
    stringKeys: Object.keys(ordered), allKeys: Reflect.ownKeys(ordered), symbol };
}
```

For this ordinary object, Object.keys yields2,10,b,a (strings); Reflect.ownKeys additionally includes the symbol last. Ordinary own-key order groups array-index strings ascending, other strings by creation order, then symbols by creation order; Object.keys also filters to enumerable string keys. This is not a universal “all object keys preserve insertion order” rule or a canonical cryptographic serialization format. Map is useful when its insertion-ordered key/value semantics are the actual contract. Proxy/custom host behavior requires its own analysis.

The fixture checks Node24.18.0 semantics, not browser availability or GC timing. Weak collections do not expose enumeration/size and do not promise when a key is collected. Feature detection for an API does not repair unsupported syntax or import resolution. Add this fixture's actual results to the version ledger, then verify the chosen browser matrix separately. A transpiler target/lib declaration alone cannot supply copying/grouping/RegExp.escape runtime APIs.
