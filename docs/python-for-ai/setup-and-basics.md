## Isolate and lock one project

A Python interpreter executes code. A virtual environment owns that project's installed packages. uv manages project resolution, the .venv and execution; pyproject.toml declares requirements and uv.lock records the resolved dependency graph/artifact information. Activation is optional when uv run selects the environment. Do not install project libraries into the operating-system Python.

Create a new learner project outside any Autocode-owned src/tests tree. Use this initial layout:

```text
python-notes-lab/
  .python-version
  pyproject.toml
  uv.lock                 # Generated by uv lock; commit to your learner project.
  basics.py
  lab_tests/
    test_basics.py
  .venv/                  # Generated environment; never commit.
```

Put3.13.11 in .python-version and use this pyproject.toml:

```toml
[project]
name = "learning-notes-python-lab"
version = "0.1.0"
requires-python = "==3.13.11"
dependencies = []

[dependency-groups]
dev = ["pytest==9.1.1"]

[tool.pytest.ini_options]
testpaths = ["lab_tests"]
addopts = "-ra"
```

```bash
# Run from the new learner project with uv and the intended interpreter available.
uv lock
uv sync --locked
uv run --locked python -c 'import sys; print(sys.version); print(sys.executable)'
uv run --locked python -m pytest
```

uv lock is an intentional dependency-resolution step. Retain the resulting lockfile; CI/repeated runs use --locked so a stale declaration/lock relationship fails instead of silently changing dependencies. A lockfile improves reproducibility; it does not guarantee identical native libraries, system packages, CPU behavior or external services. Pin the interpreter/runtime image too. Do not hand-edit transitive lock entries or commit .venv, credentials or a private package-index token.

Add a runtime dependency with uv add package and a development tool with uv add --dev package; review pyproject/lock diffs and provenance before accepting them. An import name can differ from its distribution name. Avoid naming a local file json.py, typing.py or pytest.py, which can shadow real modules. Separate runtime dependencies from test/build tools; this first lab has no runtime third-party library. Later service lessons add only what they use.

## Read Python on its own terms

Indentation defines blocks; use four spaces consistently. A colon starts an if/for/def block. Variables bind names to objects; assignment does not copy a list or dictionary. None represents absence; compare it with is None. Use == for ordinary value equality; is tests identity and is not a string/number comparison shortcut.

```python
count = 3
ratio = 7 / 2                 # 3.5: true division
floor_result = -3 // 2        # -2: floor, not truncation toward zero
remainder = 7 % 2             # 1
label = f"documents={count}"  # Explicit formatting; never interpolate secrets into logs.
if count > 0:
    label += " ready"
elif count == 0:
    label += " empty"
else:
    raise ValueError("count must be nonnegative")
```

Python integers have arbitrary precision subject to resource limits. float is binary floating point; it is not exact decimal money. str is Unicode text, bytes is encoded data: use explicit UTF-8 encode/decode at boundaries and do not mix them implicitly. len(text) counts Python code points, not UTF-8 bytes, grapheme clusters or model tokens. A character-length limit is not a token-budget calculation.

Falsy values include None, False, zero and empty collections. `if not value` can conflate valid0/empty text with missing data; check the domain explicitly. bool is a subclass of int, so isinstance(True,int) is true. Where an integer count must reject booleans, use a deliberate type check or a strict schema.

## Choose collections by meaning

| Collection | Purpose | Common mistake |
|---|---|---|
| list | Ordered mutable sequence | Aliasing/mutating another caller's list |
| tuple | Fixed immutable sequence structure | Assuming referenced nested objects become immutable |
| dict | Key/value lookup; insertion order preserved | Silently overwriting duplicate IDs |
| set | Unique hashable values/membership | Treating its iteration order as a presentation contract |

```python
original = [{"tags": ["ai"]}]
alias = original
shallow = original.copy()
alias.append({"tags": []})
assert len(original) == 2
shallow[0]["tags"].append("python")
assert original[0]["tags"] == ["ai", "python"]
assert shallow is not original  # The outer copy still shares the nested dictionary/list.

names = ["Ada", "Bela", "Ada"]
unique_in_order = list(dict.fromkeys(names))
assert unique_in_order == ["Ada", "Bela"]
assert set(names) == {"Ada", "Bela"}
lengths = {name: len(name) for name in unique_in_order}
assert lengths["Ada"] == 3
```

List/dict comprehensions are concise transformations when one expression/filter remains clear. Prefer an ordinary loop when validation, several state changes or error context would be hidden. sorted(values) returns a new list; list.sort mutates and returns None. A slice/copy is shallow. Dict keys/set members must be hashable; a list cannot be a key. Do not mutate a dictionary's size while iterating it; build another result or iterate an intentional copy.

## Worked preparation boundary

This module accepts bounded, already-loaded records, validates each record, normalizes tags and returns fresh public dictionaries. It is not a streaming file parser or a tokenizer. Reject duplicate document IDs rather than silently overwrite content, and preserve tag order while removing case-insensitive duplicates. The selected normalization strips outer body whitespace but preserves internal paragraph layout; aggressive whitespace folding can damage source meaning.

```python
# basics.py
import re

_ID = re.compile(r"[A-Za-z0-9_-]{1,64}")


def clean_tags(raw: object, /) -> tuple[str, ...]:
    if not isinstance(raw, list) or len(raw) > 10:
        raise ValueError("tags must be a list of at most10 strings")
    result: list[str] = []
    seen: set[str] = set()
    for value in raw:
        if not isinstance(value, str):
            raise ValueError("tag must be text")
        tag = value.strip().casefold()
        if not 1 <= len(tag) <= 40:
            raise ValueError("tag length out of range")
        if tag not in seen:
            seen.add(tag)
            result.append(tag)
    return tuple(result)


def normalize_document(raw: object) -> dict[str, object]:
    if not isinstance(raw, dict) or not set(raw) <= {"id", "body", "tags"}:
        raise ValueError("unexpected document shape")
    identity = raw.get("id")
    body = raw.get("body")
    if not isinstance(identity, str) or _ID.fullmatch(identity) is None:
        raise ValueError("invalid document id")
    if not isinstance(body, str) or not 1 <= len(body.strip()) <= 20000:
        raise ValueError("invalid document body")
    return {"id": identity, "body": body.strip(), "tags": clean_tags(raw.get("tags", []))}


def normalize_documents(raw: object, *, max_records: int = 100) -> list[dict[str, object]]:
    if type(max_records) is not int or not 1 <= max_records <= 1000:
        raise ValueError("invalid record budget")
    if not isinstance(raw, list) or len(raw) > max_records:
        raise ValueError("document batch exceeds budget or is not a list")
    result: list[dict[str, object]] = []
    seen: set[str] = set()
    for candidate in raw:
        document = normalize_document(candidate)
        identity = str(document["id"])  # normalize_document already established a string ID.
        if identity in seen:
            raise ValueError("duplicate document id")
        seen.add(identity)
        result.append(document)
    return result


def add_tag(tag: str, tags: list[str] | None = None) -> list[str]:
    # A fresh default per call; existing input is copied rather than mutated.
    result = [] if tags is None else list(tags)
    result.append(tag)
    return result
```

Function annotations document intended types but do not enforce them at runtime. The explicit checks enforce this boundary. Modules/typed domain objects and static checking receive a deeper lesson next; dict[str,object] is intentionally a simple first representation rather than the final service model. Content may contain untrusted instructions: normalization validates shape, not factual trust or permission to execute anything in the text.

`clean_tags(raw, /)` makes raw positional-only; `normalize_documents(raw, *, max_records=100)` makes the budget keyword-only so call sites state its meaning. Defaults are evaluated when the function is defined, not fresh on every call. A mutable default such as tags=[] would be shared across calls; None plus a new list avoids that bug. Return None explicitly when absence is part of the contract; a function without return also returns None. Assignment inside a function creates a local binding unless explicitly declared otherwise; avoid hidden global configuration/state in data-preparation functions.

The implementation uses pure result construction: it does not mutate the input, access a network, read environment variables or call a model. That makes failures reproducible. It rejects a list larger than the record budget before normalization; a later streaming lesson will bound bytes/lines before loading a file. Input type/length checks do not authorize a document or sanitize it for every possible output context.

## Executable boundary tests

```python
# lab_tests/test_basics.py — learner-project tests; never Autocode src/tests
from copy import deepcopy

import pytest

from basics import add_tag, clean_tags, normalize_documents


def test_normalization_preserves_source_and_order():
    raw = [{"id": "doc-1", "body": "  First\n\nSecond  ", "tags": [" AI ", "ai", "Python"]}]
    before = deepcopy(raw)
    result = normalize_documents(raw, max_records=2)
    assert result == [{"id": "doc-1", "body": "First\n\nSecond", "tags": ("ai", "python")}]
    assert raw == before
    assert normalize_documents([]) == []


@pytest.mark.parametrize("record", [
    None,
    {"id": "../file", "body": "text"},
    {"id": "doc", "body": "  "},
    {"id": "doc", "body": "text", "role": "admin"},
    {"id": "doc", "body": "text", "tags": [1]},
    {"id": "doc", "body": "text", "tags": [""]},
])
def test_untrusted_record_rejected(record):
    with pytest.raises(ValueError):
        normalize_documents([record])


def test_duplicate_and_budget_are_explicit():
    record = {"id": "same", "body": "text"}
    with pytest.raises(ValueError, match="duplicate"):
        normalize_documents([record, record])
    with pytest.raises(ValueError, match="budget"):
        normalize_documents([record, {"id": "other", "body": "text"}], max_records=1)
    with pytest.raises(ValueError):
        normalize_documents([], max_records=True)


def test_defaults_and_identity():
    assert add_tag("first") == ["first"]
    assert add_tag("second") == ["second"]
    source = ["existing"]
    assert add_tag("new", source) == ["existing", "new"]
    assert source == ["existing"]
    assert clean_tags(["Straße", "STRASSE"]) == ("strasse",)
    with pytest.raises(TypeError):
        clean_tags(raw=["ai"])
```

These tests check intended outputs and rejection boundaries, not whether the learner can reproduce or explain them. Use descriptive assertions and parameterization for distinct invalid categories. A passing test command with zero collected tests is not acceptance; retain the collection/result count. The later testing lesson will cover fixtures, fake I/O, integration boundaries and failures more deeply.
