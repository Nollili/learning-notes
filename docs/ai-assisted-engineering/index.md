# AI-Assisted Engineering

Use an assistant throughout development while retaining engineer ownership of scope, security, review and actual evidence. Start with one complete local example and add workflow controls in small batches. Reading generated material does not establish independent capability.

1. [Issue to a Reviewed Local Change](./issue-to-reviewed-change.md) — repository instructions, precise contracts, context and a reproduced/fixed retry bug.

2. [Verification and Permissions](./verification-and-permissions.md) — generated-code review, actual API checks, secret minimization and targeted defect challenges.

3. [Local Workflow and Git](./local-workflow-and-git.md) — repeatable stages, branches/worktrees, permissions and a factual local handoff.

4. [Traceability and Evaluation](./traceability-and-evaluation.md) — requirement-to-check matrix, candidate identity, measured workflow outcomes and honest documentation.

The worked case is a disposable study fixture. Learner practice and independent human review remain required. No remote push is permitted by this project's instructions.
