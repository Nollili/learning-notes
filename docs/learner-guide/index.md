## Your first session

1. Open the [Node path](../node-js/) and confirm you can explain functions, scope, objects, promises and try/catch. Use [specific prerequisite references](../node-js/prerequisites-and-boundaries.md) for gaps; completing the frontend curriculum is unnecessary.
2. Open [the analyzer specification](../practice/node-js/core-project.md). Read its input contract and N-01 only. Keep this tab beside the [minimum reading](./node-start.md).
3. In a separate owned learner directory, write down expected valid, empty and invalid outcomes. Attempt the small CLI independently. Do not copy a finished homework solution.
4. Keep a [progress record](./progress.md), including uncertainty. Begin meaningful checks with the first increment; do not postpone them until N-05.

Use synthetic logs, local files and loopback services. Preserve supplied Autocode build/Jest/database settings and restricted `src/tests`; run `npm run build`, `npm run test`, and Module 4's Cobertura coverage when applicable to your submission. The documentation repository itself has a separate documentation build.
