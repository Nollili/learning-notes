# E04 — Tests, gates and a justified refactor

**Learner status: outstanding.** Reuses P-336.

## Prerequisites

Small requirement and a disposable lab. Follow [the reading guide](../../engineering/quality.md).

## Scope

Reuse the TDD retry/config and minimal-standard labs; add one missing boundary and refactor a single changing policy.

## Observable acceptance

Baseline defect is detected; final tests/build pass; lint/type/test each fail their intentional negative control; original API/ownership remains correct.

## Failure cases

Vacuous assertion with high coverage, stale snapshot approval, partial-stage mismatch, aliased mutable state and a substitutability-breaking adapter.

## Evidence

Commands/exit statuses, fault variants, actual diff, decision trade-off and a real reviewer outcome only if one occurs. Retain source/tool versions, expected versus actual, failure→fix→retest and open verification gaps. Author checks never complete this increment.
