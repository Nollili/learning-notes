## Prerequisites

JS/TS, React state/effects; the existing state and frontend paths. Follow [the reading guide](../../engineering/state.md).

## Scope

Move one shared normalized entity read/write path into a single owner; retain URL, dirty draft and server cache boundaries.

## Observable acceptance

Unchanged references remain stable; dangling snapshots reject atomically; account switch isolates state; B-before-A cannot publish A; abort/error produces truthful UI.

## Failure cases

Duplicate IDs, malformed response, ignored abort, stale selector, two store instances, invalid persisted schema.
