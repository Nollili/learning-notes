# E06 — Architecture and operational decision

**Learner status: outstanding.** Reuses P-328/P-331/P-333/P-337.

## Prerequisites

One working vertical slice. Follow [the reading guide](../../engineering/design.md).

## Scope

Write one ADR, quality scenario, revised estimate and bounded incident/recovery rehearsal using the same product.

## Observable acceptance

Requirement maps to observed check, proposed versus measured budgets remain distinct, chosen datastore preserves invariant and recovery limits have an owner.

## Failure cases

Concurrent stock decrement, duplicate SKU, stale replica/cache, failed restore step, misleading liveness and missing external dependency.

## Evidence

Decision alternatives/cost, actual failure/recovery record and handoff. No invented stakeholders, incident history, deployment or cost quote. Retain source/tool versions, expected versus actual, failure→fix→retest and open verification gaps. Author checks never complete this increment.
