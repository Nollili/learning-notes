# E05 — Local integration and release integrity

**Learner status: outstanding.** Reuses P-333/P-336.

## Prerequisites

Git basics, known clean disposable repo, primary artifact/DB lessons. Follow [the reading guide](../../engineering/delivery.md).

## Scope

Reproduce merge/rebase conflict/abort/recovery locally and promote one verified local artifact through separate consumer directories. No push/publication.

## Observable acceptance

Resolve by behavior contract, preserve recovery reference, required gate blocks bad candidate, artifact identity matches, unsafe rollback is explicitly refused.

## Failure cases

Dirty/partial-stage state, absent artifact/cache, tampered bytes, order-dependent test, incompatible schema or stale migration writer.

## Evidence

Old/new commit and artifact identities, build/test outcomes, compatibility matrix and exact unperformed hosted/traffic/restore limits. Retain source/tool versions, expected versus actual, failure→fix→retest and open verification gaps. Author checks never complete this increment.
