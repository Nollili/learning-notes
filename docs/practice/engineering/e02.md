# E02 — Measured performance

**Learner status: outstanding.** Reuses P-328/P-329.

## Prerequisites

Working flow and declared device/data/artifact. Follow [the reading guide](../../engineering/performance.md).

## Scope

Investigate one cold-load or input/scroll bottleneck in that same product, change one cause and repeat comparable runs.

## Observable acceptance

Keep expected content/accessibility behavior; retain repeated raw timings/traces, cache conditions and variance. Bound retained data/owners.

## Failure cases

Slow font/data, late dependency, long sync task, background/visibility and failed request; reject misleading best-run-only comparisons.

## Evidence

Baseline/fix traces, actual browser/tool/workload, measured regression and remaining real-device/field gaps. Retain source/tool versions, expected versus actual, failure→fix→retest and open verification gaps. Author checks never complete this increment.
