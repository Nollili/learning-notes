# F01 — HTML, forms and focus

**Learner status: outstanding.**

## Prerequisites

HTML/browser lesson and semantic-form examples. Reuse P-328’s initial native table/form increment.

## Scope

Implement the public GET search without JavaScript, then enhance it. Add one named native modal for a reversible local confirmation; it performs no external action.

## Observable acceptance

Keyboard Enter submits; native invalid input prevents normal submission; bypassed invalid input is rejected by the server. Tab/Shift+Tab and Enter/Space work. Modal entry, Tab containment, Escape/cancel and trigger/fallback focus are observed. Error summary links reach fields; status reports only confirmed outcomes.

## Failure cases

Missing module, failed JSON, empty query, repeated query keys, long Unicode input, removed dialog trigger, and no-JS navigation.

## Evidence to record

Retain HTML/HTTP results and exact keyboard traces. Record browser/OS/reader versions and actual name/description/status observations. Screen-reader, 200% text enlargement, 400% zoom and real-device checks require real observations; leave them open until performed.
