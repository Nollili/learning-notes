# Practice: Can we write code in TS if we would like to support older browsers?

**Status: outstanding learner practice.** Author checks do not complete these requirements.

Prerequisite: study the [worked lesson](../../../senior_growth/TypeScript/Can_we_write_code_in_TS_if_we_would_like_to_support_older_browsers.md) and its linked foundations. Apply these focused cases to [P-328/P-329/P-330](../../frontend-project.md); retain only the cases relevant to the chosen increment.

## Scope and observable criteria

**Exercise:** build a small page using an import, async function, fetch and an array API. Acceptance: record compiler/bundler versions, list syntax/API/module requirements, inspect the generated bundle, demonstrate one failure caused by a missing API, then verify the corrected page in each declared browser. Advanced legacy-device testing requires access to those devices; do not claim it from a local modern-browser run.

## Evidence

Record source revision, runtime/browser versions, expected versus observed result, one reproduced failure, correction and retest. Include exact commands or input sequence and artifacts. Mark unperformed keyboard, screen-reader, zoom, device and integration checks explicitly. Never record a supplied example as your completed practice.
