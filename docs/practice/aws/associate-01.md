## A01.1 — Create or recheck the account — repeating P01

- [ ] Create and activate an account using the official registration guidance, or recheck the account already used for P01. Investigate support restrictions if a required service cannot be enabled.

## A01.2 — Secure the account — repeating P01

- [ ] Protect root credentials, enable MFA, avoid everyday root use, and configure an MFA-protected admin identity with the course-required console/programmatic access.
- [ ] Apply least privilege to exercise users, groups and service roles. Inspect managed policies and create scoped policies where needed.
- [ ] Configure and inspect the IAM-user password policy. Do not create root access keys for this exercise.

## A01.3 — Configure CLI — repeating P01

- [ ] Install CLI, authenticate with the course admin identity and deliberately select the default Region. Confirm the caller/account rather than assuming the console and terminal match.

## A01.4 — Alerts — repeating P01

- [ ] Enable applicable Free Tier notifications.
- [ ] Configure email budget notifications at **40%, 80% and 100%** of the selected limit; retain evidence of the actual settings.
- [ ] Inventory learning resources across relevant Regions and plan cleanup. Do not remove the account or shared resources needed by later labs.
